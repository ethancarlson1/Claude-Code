How it works

  1. The AI reads everything you upload and answers the same questions as your client request form: date, venue, load-in, parking, timeline, contacts, attendance, gear and so on.
  2. You check it. Each answer shows the line from the document it came from, so mistakes are easy to spot. Anything that doesn't fit a question is listed too.
  3. Add it to an event, or create an inquiry. Adding only fills in what the event is missing; anything that differs from what you already have goes into the office notes. The files go to the event's Documents tab.

The files are sent to Anthropic to be read. By default, Anthropic doesn’t use what’s sent through its API to train its AI. Each import costs a few cents; see Settings → AI import.
